# BaseChatClientServer
Консольный TCP-чат на C: один сервер и несколько клиентов. Сообщения идут строками, каждое сообщение — ник и текст на отдельных строках.
Сервер слушает порт **12345** на всех интерфейсах (`INADDR_ANY`). Клиент подключается только к **127.0.0.1**.
## Сборка
Нужны CMake 3.15+, компилятор C11 и POSIX-потоки (`pthread`).
```bash
cmake -S . -B build
cmake --build build
```
Бинарники: `build/Server` и `build/Client`.
## Запуск
Сначала сервер. Он спросит максимальное число пользователей (целое число ≥ 1) и начнёт принимать подключения:
```bash
./build/Server
```
В другом терминале — клиент:
```bash
./build/Client
```
После подключения сервер запросит ник. Ник должен быть уникальным и короче 32 символов. Если лимит мест исчерпан или ник занят, соединение закрывается.
Обычный текст рассылается всем, кроме отправителя. Пустые строки сервер не рассылает.
## Команды клиента
| Команда | Действие |
| --- | --- |
| `/EXIT` | Выйти из чата |
| `/USERS` | Список активных ников |
| `/USER <ник>` | Личное сообщение: после команды клиент спросит текст |
## Команды сервера
| Команда | Действие |
| --- | --- |
| `/STOP` | Остановить сервер: сокет закрывается, новые подключения не принимаются |
## Ограничения
- Порт задан в коде: `SERVER_PORT` в `src/server.h` и `src/client.h`.
- Адрес клиента зашит как `127.0.0.1`.
- Длина ника — до 31 символа, сообщения — до 255 символов.
- Шифрования и авторизации нет.
